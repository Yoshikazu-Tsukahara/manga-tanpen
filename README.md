# AI漫画 → ショート動画メーカー（プロトタイプ）

縦につないだ4コマの原稿の上を、9:16のカメラが「止まる → 寄る → 止まる」と緩急をつけてパンしていく様子をプレビューできるモックアップです。React + Tailwind CSS のみで作っており、動画ライブラリやアニメーションライブラリは使っていません。

## 起動方法

```bash
npm install
npm run dev
```

## 操作

- **コマをクリック**：その位置に画像をアップロード（未設定の間はスクリーントーン風のダミー）
- **赤いカメラ枠のつまみ／右端のバーをドラッグ**：カメラ位置を手動で移動
- **▶ 再生 / スペースキー**：台本どおりにカメラが1コマ目から4コマ目へ
- **タイムライン帯**：濃い帯が「停留」、薄い帯が「移動」。クリック／ドラッグでシーク
- **停留・移動スライダー**：各コマで止まる秒数と、次のコマへ寄る秒数
- **表示倍率**：原稿全体の俯瞰と、コマを大きく見る表示を切り替え（再生中は自動追従）

## 仕組み

### サイズ設計（`src/layout.js`）

キャンバスとカメラのサイズを「仮想単位」の比率だけで定義しています。実ピクセルを持たないので、ワークスペース（俯瞰表示）とプレビュー（スマホサイズ）で同じ `MangaCanvas` をそのまま使い回せます。

コマ1枚の高さはカメラフレーム（9:16）の高さと同じ値にしてあり、カメラがコマに合わさるとそのコマが画面いっぱいにピッタリ収まります。

### カメラワーク（`src/timeline.js`）

一定速度で流すのをやめ、`停留(hold) → 移動(move) → 停留(hold) → …` というステップの並び（台本）として組み立てています。アプリが持つ状態は「経過時間 `time`」だけで、そこから `progress`（0〜1のカメラ位置）を計算します。

- 停留ステップ：`progress` は動かない（絵を読ませる間）
- 移動ステップ：`easeInOutCubic` でなめらかに加速・減速しながら次のコマへ

カメラ枠を手でドラッグしたときは逆に「位置 → 時間」を二分探索で逆算し、タイムライン側の再生位置も合わせています。

### 2つのビューの同期

- ワークスペース：カメラ枠の `top` を `progress × 移動可能距離(%)` にする
- プレビュー：9:16 の枠を `overflow: hidden` にし、中の原稿を `translateY(-progress × 移動可能距離(%))` でずらす

同じ `progress` から同じ % を計算しているため、2つのビューは常にぴったり一致します。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `src/layout.js` | 原稿・コマ・カメラの比率計算 |
| `src/timeline.js` | 停留と移動からなる台本、時間↔カメラ位置の変換 |
| `src/components/MangaCanvas.jsx` | 4コマが縦に並んだ原稿本体 |
| `src/components/Workspace.jsx` | 俯瞰表示＋カメラ枠のドラッグ・表示倍率・自動追従 |
| `src/components/VideoPreview.jsx` | スマホ枠（9:16）の切り抜きプレビュー |
| `src/components/TimelineBar.jsx` | 停留／移動を帯で表したタイムライン |
| `src/App.jsx` | 状態管理（経過時間・再生・画像）と操作パネル |
